# WinDebSc: Windows Debloating & Automation Suite

Aplicación desarrollada en **Java** para automatizar el proceso de optimización, privacidad y eliminación de software prescindible (*debloat*) en sistemas operativos Windows.

Inspirado en herramientas comunitarias como *WinUtil* de Chris Titus, este proyecto implementa un orquestador modular en Java con soporte para ejecución segura de scripts PowerShell y documentación académica rigurosa estilo TFG.

---

## Estructura del Proyecto

- **`docs/`**: Memoria completa del proyecto en LaTeX (compilable con TeXworks / pdflatex).
- **`scripts/`**: Scripts de PowerShell modulares organizados por categorías (Telemetría, Servicios, Apps, Optimización).
- **`src/`**: Código fuente de la aplicación de escritorio en Java.

---

## Requisitos

- **Java**: JDK 17 o superior (desarrollado con OpenJDK 26).
- **Sistema Operativo**: Windows 10 / 11 (recomendado probar en máquina virtual).
- **LaTeX**: Distribución MiKTeX o TeX Live (editor recomendado: TeXworks o VS Code).
